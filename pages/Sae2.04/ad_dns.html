Active Directory & DNS — Windows Server

Présentation

L'Active Directory (AD) est un service d'annuaire Microsoft qui centralise la gestion des identités, des utilisateurs, des ordinateurs et des ressources du réseau. Le domaine créé est brasserie.local.

L'AD repose entièrement sur le DNS pour fonctionner. Sans DNS, les PC clients ne peuvent pas localiser le Contrôleur de Domaine et rejoindre le domaine.

Étape 2 — Installation du rôle AD DS

  1. Gestionnaire de serveur → Ajouter des rôles et fonctionnalités
  2. Cocher Active Directory Domain Services
  3. Cocher aussi DNS Server (obligatoire)
  4. Installer

Étape 3 — Promotion en Contrôleur de Domaine

  1. Drapeau jaune → Promouvoir ce serveur en contrôleur de domaine
  2. Choisir Ajouter une nouvelle forêt
  3. Nom de domaine racine : brasserie.local
  4. Niveau fonctionnel : Windows Server 2022
  5. Cocher : Serveur DNS + Catalogue global
  6. Mot de passe DSRM : Brasserie@2026!
  7. Installer → le serveur redémarre automatiquement

Configuration DNS

Forwarder vers le DNS de la salle

  1. dnsmgmt.msc → clic droit sur le serveur → Propriétés → onglet Redirecteurs
  2. Le forwarder 192.168.117.181 était déjà présent automatiquement

Résultat : brasserie.local est résolu par le serveur Windows, et google.com est transféré au DNS de la salle.

Enregistrement DNS pour le site web

  1. dnsmgmt.msc → clic droit sur brasserie.local → Nouvel hôte (A)
  2. Nom : www | IP : 192.168.136.11
  3. Ajouter un hôte

Jonction d'un PC client au domaine

  1. Windows + Pause → Paramètres avancés du système → Modifier
  2. Sélectionner Domaine → taper brasserie.local
  3. Login : Administrateur | MDP : Admin123
  4. Message "Bienvenue dans le domaine brasserie.local" → Redémarrer
  5. Se connecter avec employe1 / Brasserie@2026

Problèmes rencontrés

Problème 1 — Erreur TCP/IP lors de la promotion

Cause : Le serveur n'avait pas d'IP fixe configurée.

Solution : Configurer une IP fixe avant de relancer l'assistant AD.

Problème 2 — PC client ne trouve pas le domaine

Cause : Le DNS du PC client pointait vers 192.168.117.181 qui ne connaît pas brasserie.local.

Solution : Modifier l'option 006 dans le DHCP pour distribuer 192.168.136.51 comme DNS.

Problème 3 — Mauvais mot de passe pour rejoindre le domaine

Cause : Utilisation du mot de passe Brasserie@2026! au lieu de Admin123.

Solution : Le mot de passe du compte Administrateur du serveur est Admin123.
