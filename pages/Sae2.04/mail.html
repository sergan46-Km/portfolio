Serveur de Messagerie — Postfix & Dovecot

Présentation

Le serveur de messagerie permet aux employés de la brasserie de s'envoyer des emails en interne via leur propre domaine @brasserie.local. Tout le trafic mail reste dans le réseau interne, ce qui garantit la confidentialité des communications.

ServiceRôlePort
PostfixEnvoi des emails (SMTP)25
DovecotRéception et stockage (IMAP)143
DovecotRéception et stockage (POP3)110

Installation

Important : Il faut installer les 4 paquets Dovecot d'un coup. Si on installe seulement dovecot-imapd, Dovecot refusera de démarrer car les services pop3-login et lmtp seront manquants.

sudo apt update && sudo apt upgrade -y
sudo apt install postfix dovecot-core dovecot-imapd dovecot-pop3d dovecot-lmtpd -y

Configuration de Postfix

sudo dpkg-reconfigure postfix

Configuration de Dovecot

sudo nano /etc/dovecot/conf.d/10-auth.conf
  • Décommenter et modifier : disable_plaintext_auth = no
  • Décommenter et modifier : auth_mechanisms = plain login

Génération des certificats SSL

sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout /etc/dovecot/private/dovecot.key \
-out /etc/dovecot/private/dovecot.pem \
-subj "/CN=brasserie.local"

Démarrage des services

sudo systemctl restart postfix
sudo systemctl restart dovecot
sudo systemctl status postfix
sudo systemctl status dovecot

Création des utilisateurs Linux

Les adresses mail sont automatiquement liées aux comptes Linux :

sudo useradd -m -s /bin/bash employe1 && sudo passwd employe1
sudo useradd -m -s /bin/bash employe2 && sudo passwd employe2
sudo useradd -m -s /bin/bash direction1 && sudo passwd direction1
sudo useradd -m -s /bin/bash admin1 && sudo passwd admin1

Mot de passe pour chacun : Brasserie@2026

Adresses mail créées :

  • employe1@brasserie.local
  • employe2@brasserie.local
  • direction1@brasserie.local
  • admin1@brasserie.local

Test de l'envoi d'un email

echo "Test mail brasserie" | mail -s "Test" admin1@brasserie.local
sudo cat /var/mail/admin1

Vérification de la configuration

# Vérifier la configuration Postfix
sudo cat /etc/postfix/main.cf

# Vérifier la configuration Dovecot
sudo dovecot -n

# Vérifier que les ports sont ouverts

Problèmes rencontrés

Problème 1 — Dovecot ne démarre pas : pop3-login manquant

Cause : Seul dovecot-imapd avait été installé.

Solution : sudo apt install dovecot-core dovecot-imapd dovecot-pop3d dovecot-lmtpd -y

Problème 2 — Erreur mail_location: Unknown setting

Cause : Dans Dovecot 2.4, mail_location n'existe plus, remplacé par mail_driver et mail_path.

Solution : Ne pas ajouter mail_location, laisser la config par défaut de Dovecot 2.4.

Problème 3 — Connexion Thunderbird échoue

Cause 1 : Login avec admin1@brasserie.local au lieu de admin1.

Cause 2 : Sécurité IMAP sur Aucune au lieu de Par défaut.

Solution : Login = admin1 sans domaine | IMAP sécurité = Par défaut | SMTP sécurité = Aucune.
