Gestion de Projet

Présentation de l'équipe

Le projet SAE 204 a été réalisé par une équipe de 4 étudiants en BUT Réseaux & Télécommunications à l'Université Clermont Auvergne. Chaque membre a pris en charge un domaine spécifique de l'infrastructure.

MembreRôle principal
Mohamed Abou FirnasDéveloppement web & Base de données
Bassaiev MalikSystèmes Linux, Syslog & Sécurité applicative
Duverger ElliotInfrastructure réseau physique & Équipements
Ali KassimActive Directory, GPO & Services Windows

Mohamed Abou Firnas — Développement Web & Base de données

  • Développement du site web de la brasserie
  • Conception et gestion de la base de données MySQL

Bassaiev Malik — Systèmes Linux, Syslog & Sécurité

  • Installation des systèmes d'exploitation (Debian Linux et Windows Server)
  • Intégration du serveur mail et de Syslog dans le site web
  • Configuration de Syslog (scripts PowerShell et Bash)
  • Installation et configuration du serveur web (Apache2, MySQL)
  • Réparation d'Asterisk (serveur de téléphonie)
  • Rédaction du dossier technique
  • Passage du site web en HTTPS (certificat SSL)
  • Sauvegarde automatisée de la base de données SQL
  • Masquage du token du serveur Apache (sécurité)

Duverger Elliot — Infrastructure réseau physique

  • Configuration du routeur (VLANs, NAT, PAT, routage inter-VLAN)
  • Configuration du switch (VLANs, trunk, ports access)
  • Configuration du pare-feu physique (règles de filtrage, DMZ)
  • Configuration du point d'accès Wifi employés (brasserie-employe)
  • Câblage et gestion de baie
  • Réparation après erreurs de configuration
  • Configuration du DHCP (étendues, options)
  • Configuration de la téléphonie (Asterisk)
  • Serveur web (participation)
  • Rédaction du compte rendu

Ali Kassim — Active Directory, GPO & Services Windows

  • Configuration du point d'accès Wifi client (brasserie-client, VLAN 60)
  • Configuration du serveur DNS (zone brasserie.local, forwarder)
  • Installation et configuration de l'Active Directory
  • Création du domaine brasserie.local
  • Création des Unités Organisationnelles (Employes, Direction, Admin)
  • Création et gestion des groupes de sécurité (GRP_Admin, GRP_Direction, GRP_Employes)
  • Gestion des permissions utilisateurs
  • Configuration des GPO (securite-Globale, Audit-Logs, Restrictions-Employes, Restrictions-Directions, Fonds d'écran)
  • Configuration de l'accès à distance RDP (admin sur serveur Windows)
  • Configuration du pare-feu Windows Defender (règles RDP et gestion à distance)
  • Configuration des logs Windows (eventvwr, ID 4625, 4740)
  • Participation à la configuration de la téléphonie (Asterisk, PJSIP)
  • Rédaction du compte rendu web (pages HTML/CSS)

Tâches réalisées en groupe

  • Tests de connectivité inter-VLAN
  • Validation des services réseau
  • Tests de sécurité (DHCP Snooping, attaques)
  • Corrections des erreurs et dépannage
  • Démonstrations finales
  • Préparation de la soutenance

Bilan du projet

Le projet s'est bien déroulé dans l'ensemble. La répartition des tâches a permis à chaque membre de se spécialiser dans un domaine tout en ayant une vision globale de l'infrastructure.

Points positifs

  • Bonne communication entre les membres de l'équipe
  • Infrastructure fonctionnelle et conforme aux objectifs
  • Résolution efficace des problèmes rencontrés
  • Documentation complète réalisée tout au long du projet

Difficultés rencontrées

  • Asterisk non disponible dans les dépôts Debian 13 → compilation depuis les sources
  • Dovecot 2.4 avec nouvelle syntaxe différente des versions précédentes
  • Fond d'écran GPO : chemin UNC avec IP ne fonctionnait pas, il fallait utiliser le nom NetBIOS
  • Coordination entre les deux TD (groupe A et groupe B) pour les décisions d'architecture
