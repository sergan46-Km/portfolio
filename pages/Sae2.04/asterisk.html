Serveur de Téléphonie — Asterisk PBX

Présentation

Asterisk est un logiciel open-source de serveur téléphonique (IPBX) installé sur le serveur Linux. Il permet de gérer les appels internes entre les différents services de la brasserie via le protocole VoIP (Voice over IP) avec PJSIP.

ParamètreValeur
Version installéeAsterisk 20.20.0
ProtocolePJSIP (SIP moderne)
PortUDP 5060
Serveur192.168.136.54 (Linux)
Softphone clientMicroSIP

Installation

Pourquoi compiler depuis les sources ?

Le paquet asterisk n'est pas disponible dans les dépôts officiels de Debian 13. Il est donc nécessaire de le compiler depuis les sources officielles.

Étape 1 — Installation des dépendances

sudo apt install build-essential wget libssl-dev libncurses5-dev \
libnewt-dev linux-headers-$(uname -r) libsqlite3-dev uuid-dev -y

Étape 2 — Téléchargement et compilation

cd /usr/src
sudo wget http://downloads.asterisk.org/pub/telephony/asterisk/asterisk-20-current.tar.gz
sudo tar -xvzf asterisk-20-current.tar.gz
cd asterisk-20*/
sudo contrib/scripts/install_prereq install
./configure --with-jansson-bundled
make -j$(nproc)
sudo make install
sudo make samples
sudo make config

Note : La commande make -j$(nproc) utilise tous les cœurs du processeur pour accélérer la compilation. Cette étape peut prendre 10 à 15 minutes.

Étape 3 — Démarrage du service

sudo systemctl start asterisk
sudo systemctl status asterisk

Configuration PJSIP

Fichier pjsip.conf

Chemin : /etc/asterisk/pjsip.conf

Ce fichier définit le transport UDP et les comptes SIP de chaque utilisateur.

[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0

[employe1]
type=endpoint
context=brasserie
disallow=all
allow=ulaw
auth=employe1-auth
aors=employe1-aor

[employe1-auth]
type=auth
auth_type=userpass
username=employe1
password=Brasserie@2026

Fichier extensions.conf

Chemin : /etc/asterisk/extensions.conf

Ce fichier définit les numéros de poste de chaque utilisateur.

[brasserie]
exten => 100,1,Dial(PJSIP/employe1)
exten => 101,1,Dial(PJSIP/employe2)
exten => 200,1,Dial(PJSIP/direction1)
exten => 300,1,Dial(PJSIP/admin1)

Commandes utiles

Gestion du service

sudo systemctl start asterisk
sudo systemctl restart asterisk
sudo systemctl status asterisk

Console Asterisk CLI

sudo asterisk -rvv           # Se connecter à la console
pjsip show endpoints         # Afficher les endpoints configurés
pjsip show transports        # Afficher les transports
pjsip show registrations     # Afficher les enregistrements
pjsip set logger on          # Activer les logs PJSIP
pjsip reload                 # Recharger la config PJSIP
dialplan reload              # Recharger le dialplan
dialplan show brasserie      # Afficher les extensions du contexte
core show version            # Afficher la version
exit                         # Quitter la console

Vérification des ports

sudo ss -ulnp | grep 5060    # Vérifier qu'Asterisk écoute sur UDP 5060

Problèmes rencontrés

Problème 1 — Le paquet asterisk n'est pas disponible dans les dépôts Debian 13

Cause : Asterisk n'est pas packagé pour Debian 13 (Trixie).

Solution : Compiler depuis les sources officielles avec ./configure --with-jansson-bundled.

Problème 2 — Asterisk ne démarre pas après installation

Cause : Des processus Asterisk orphelins tournaient en arrière-plan.

Solution : sudo killall -9 asterisk puis sudo /usr/sbin/asterisk -vvvg &

Problème 3 — MicroSIP retourne 404 Not Found lors de l'enregistrement

Cause : Les sections dans pjsip.conf n'étaient pas correctement séparées (pas de ligne vide entre les blocs).

Solution : Ajouter une ligne vide entre chaque section [endpoint], [auth] et [aor] dans pjsip.conf.

Problème 4 — Les endpoints restent en statut "Unavailable"

Cause : Le client SIP n'arrivait pas à s'enregistrer à cause d'un problème d'authentification.

Solution : Utiliser pjsip set logger on dans la console Asterisk pour voir les échanges SIP et diagnostiquer le problème.
